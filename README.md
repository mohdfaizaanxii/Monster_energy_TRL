# Monster Energy® - 3D Interactive Web Experience

A high-performance e-commerce and interactive showcase web experience built with:
- **Canvas Scrollytelling**: High-FPS frame-by-frame 3D product scrubbing
- **3D WebGL Flavour Vault**: Interactive procedural sphere gallery (`InfiniteMenu`)
- **PillNav Navigation**: Floating interactive navigation dock with sound effects and responsive design
- **Audio Engine**: Interactive cyberpunk sound effects and synth audio ambiance
- **Responsive E-Commerce Engine**: Multi-pack selection, dynamic pricing, and cart drawer

## Quick Start
Open `index.html` directly in a browser or serve via any static web server (e.g., Live Server, Python HTTP server, or Node.js http-server).
